# App Fullstack

Projeto de estudo full-stack com backend Java/Spring Boot para cadastro e consulta de pessoas. A API usa controller, entidade e repositório Spring Data JPA.

## Stack
- Java e Spring Boot
- Spring Web
- Spring Data JPA
- Maven

## Como executar
Entre no módulo Spring Boot e execute o Maven Wrapper:

```bash
cd senai-app-spring_v1
./mvnw spring-boot:run
```

No Windows, use `mvnw.cmd spring-boot:run`.
