# Full-Stack App

A full-stack study project with a Java/Spring Boot backend for creating and retrieving people records. The API uses a controller, entity, and Spring Data JPA repository.

## Stack
- Java and Spring Boot
- Spring Web
- Spring Data JPA
- Maven

## Run
Enter the Spring Boot module and run the Maven Wrapper:

```bash
cd senai-app-spring_v1
./mvnw spring-boot:run
```

On Windows, use `mvnw.cmd spring-boot:run`.
